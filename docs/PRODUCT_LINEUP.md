# Demuxer Product Lineup

## Overview

Demuxer is a series of sensor-packed glove controllers that are designed to translate natural hand, finger, and wrist movements into reliable and responsive game controls. The product lineup spans from entry-level models to high-end cyber-arm like devices.

## Target Users

- **PC Gamers**: Enthusiasts wanting motion and finger-based gaming controls
- **VR/AR Users**: Individuals seeking more natural hand input for immersive experiences
- **Accessibility Players**: Gamers needing alternative input methods for an inclusive experience

## Key Features

- **Flex Sensors**: Detect finger bends and grips across five fingers for precise input
- **Palm Foil Contacts**: Innovative touch-based input technology using conductive pads
- **6DOF IMU**: Acceleration and gesture detection for advanced wrist command inputs
- **Forearm Touchscreen**: Provides additional control options and system settings access
- **Pointer Device**: Wiimote-like dual-light emitters for point-and-click support
- **Haptic Feedback**: Delivers realistic feedback for enhancing gameplay immersion
- **Autoclick Mechanism**: Supports rapid input through fingertip vibration motors for ease of use

## Development & Open Questions

Key development areas include understanding the exact number/layout of foil contacts, designing the touchscreen interface, optimizing battery capacity and runtime, and deciding on wired vs. wireless priorities for different platforms. Each of these considerations ensures that end-users receive the best possible experience tailored to their specific needs.
