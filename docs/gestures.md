# gesture reference

complete list of gestures the Demuxer Init supports and their default mappings.

---

## IMU gestures (wrist/arm)

| gesture | motion | default action |
| --- | --- | --- |
| quick arm push forward | melee / dash / push |
| quick arm pull back | block / pull |
| wrist flick left | action 1 / move left |
| wrist flick right | action 2 / move right |
| rotate wrist clockwise | volume up / zoom in |
| rotate wrist counterclockwise | volume down / zoom out |
