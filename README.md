## Demuxer Init — Full Spec

### Overview

A sensor-packed glove controller that tracks finger bends, uses palm-mounted buttons, haptic feedback, and detects wrist gestures with a 6DOF sensor, plus a forearm touchscreen for extra controls and IoT features.

**Primary goal:** Translate natural hand/finger/wrist movement into reliable game inputs while keeping common controls easy to reach.

# Built-in Defaults

- Flash drive / SD card — plug into arm dock, system scans `/Alarm Sounds/` folder
- Web-to-arm client (Protocol+) — upload via browser, arm receives + stores file, UI refreshes instantly
- Built-in defaults

**Supported formats:** `.wav` `.ogg` `.mp3` `.dmxsfx`

**Sound output modes:** `ARM_SPEAKER`, `PHONE`, `BLUETOOTH_DEVICE`, `ALL`

**Fallback audio:** if phone disconnects mid-alarm, automatically switches to arm speaker — alarm never fails.

**Alarm actions:** call phone / play sound / vibration only
