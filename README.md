## Gaming Glove Feature

### Overview
The `Demuxer` device includes a "Gaming Glove" feature aimed at enhancing the gaming experience for PC gamers and VR/AR users. The glove provides motion and finger-based controls, allowing for a more immersive interaction in gaming environments.

### Target Users
- PC gamers who desire intuitive motion controls.
- VR/AR users looking for natural hand input options.
- Accessibility-oriented players requiring alternative input methods.

### Setup Instructions
1. Ensure the `Demuxer` device is paired with the Gaming Glove.
2. Select the Gaming Glove profile within the device settings.
3. Calibrate motion sensors according to the guided steps in the application.
4. Begin exploring enhanced controls within your favorite games.

For detailed instructions, refer to the Glove Setup Guide provided within the application.
