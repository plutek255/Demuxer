# Contributing to Demuxer

We welcome contributions to the Demuxer project. Here are a few guidelines to follow:

## Bug Reports and Feature Requests

Use GitHub issues for bug reporting and feature requests. Ensure your issue is clear and concise.

## Code Contribution

1. Fork the repository and create your branch from `main`.
2. Ensure your code adheres to the project's coding style.
3. Test your code thoroughly.
4. Open a pull request and provide a clear description of your changes.

## Style Guide

- Follow the coding standards as defined in the `.clang-format` file.
- Write clear, concise commit messages.

## Running Tests

Ensure the project builds without errors and all existing tests pass:
```bash
cmake ..
make
make test
```
