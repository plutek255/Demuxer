# Contributing to BlueJay Demuxer

Thanks for being here. This doc covers how to contribute ideas, report things, and share builds.

---

## Comment & Contribution Types

### 💡 Feature Requests
Use this when you want to suggest something new — a sensor mode, gesture, UI feature, software integration, etc.

**How to submit:**
1. Open a new issue
2. Title it clearly: `[Feature] Your idea here`
3. Describe what it does and why it's useful
4. Include any reference hardware, links, or prior art if relevant

**Good feature requests include:**
- What problem it solves or what it enables
- Whether it fits Init hardware or is better for a future model (Olympian, GX, etc.)
- Any tradeoffs (power, weight, complexity)

---

### 🧠 Ideas / Discussion
For loose concepts, brainstorming, or things you're not sure about yet.

**How to submit:**
1. Open an issue or use the Discussions tab
2. Title it: `[Idea] Your concept here`
3. Keep it open-ended — these don't need to be fully formed

Ideas may get promoted to Feature Requests or added to the roadmap.

---

### 🔨 Builds / Forks
If you built your own version of the Demuxer (remixed, modified, or inspired by this project):

**How to share:**
1. Open an issue titled: `[Build] Your build name / description`
2. Include:
   - What you changed or adapted
   - Your hardware setup
   - Photos, videos, or repo link if you have them
   - A link back to this repo (per the license request)

Build posts are welcome at any stage — prototype, WIP, or finished.

---

## General Rules

- Be respectful and specific
- No spam or off-topic posts
- Hardware questions are welcome — this is a DIY project
- If you're unsure which category fits, just pick the closest one
